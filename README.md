# Laboratory Work No. 3



## Topic

**\*\*Development of a Command-Line Application for Library Data Management\*\***

## Objective

To develop a command-line application using JavaScript, Node.js, and the Commander.js library to manage library data stored in JSON format.



## Main Features

* Displaying the list of books.
* Retrieving information about a specific book.
* Searching for books by author.
* Checking book availability.
* Viewing the history of book copies.
